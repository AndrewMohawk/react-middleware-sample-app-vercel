# react-middleware-sample-app-vercel

Minimal Next.js App Router sample for testing Vercel deployments.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm install
npm run build
npm run start
```

## Environment

Optional:

```bash
PROTECTED_DEMO_SECRET=example-value
```
